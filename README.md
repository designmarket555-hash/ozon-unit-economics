# Ozon Unit Economics

Рабочая первая версия интерфейса для плановой юнит-экономики и подготовки фактического P&L Ozon. Приложение не использует сторонние runtime-зависимости и собирается локально без доступа к внешним CDN.

## Разделы

- **Калькулятор цены** — ручной расчёт экономики одной продажи.
- **Факт P&L Ozon** — локальная загрузка отчёта по начислениям (`Начисления`, заголовок во 2-й строке) и справочника себестоимости (`OZON`, заголовок в 6-й строке), сопоставление по артикулу и расчёт результата.

Поддерживается современный формат `.xlsx`. Файлы читаются JavaScript-кодом непосредственно в браузере: приложение не загружает их на сервер и нигде не сохраняет. Значение себестоимости используется без автоматической корректировки НДС.

Источником факта сейчас является «Excel-отчёт Ozon». Архитектура интерфейса предусматривает последующее добавление Ozon API только для чтения.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm test
npm run lint
npm run build
```

Не добавляйте реальные отчёты, API-ключи и секреты в репозиторий.
