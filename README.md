# Ozon Unit Economics

Рабочая первая версия интерфейса для плановой юнит-экономики и подготовки фактического P&L Ozon. Приложение не использует сторонние runtime-зависимости и собирается локально без доступа к внешним CDN.

## Разделы

- **Калькулятор цены** — ручной расчёт экономики одной продажи.
- **Факт P&L Ozon** — подготовка ручной загрузки отчёта по начислениям и справочника себестоимости. На первом этапе файлы выбираются локально, а разбор строк и классификация начислений будут реализованы отдельно после сверки модели.

Источником факта сейчас является «Excel-отчёт Ozon». Архитектура интерфейса предусматривает последующее добавление Ozon API только для чтения.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm test
npm run lint
npm run build
```

Не добавляйте реальные отчёты, API-ключи и секреты в репозиторий.
